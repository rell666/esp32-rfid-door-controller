    Factory reset

    This cannot be undone.

    It permanently deletes all users, settings and logs, and the exit-button settings kept for power-up: the exit buttons stop opening their doors until the board is set up again. The relays stay locked at power-up. Make a backup first.

    Confirm the admin password

    Opening a door from this page, a restart, an update or factory reset, adding users, admin access and PINs, clearing the logs, setting the clock and changes to the network, MQTT or Doors & Readers settings need the admin password, not just this signed-in page.

    This reader still uses the factory password admin. Set a new one before continuing.

    Update firmware

    Make a backup first.

    Upload an Ironframe RFID ESP32-S3 firmware image (esp32s3.bin, not the -full-flash / -full image). Upstream esp-rfid releases are ESP8266 builds and will not run on this board.
